# UI Delivery Checklist

> UI 交付或审查时按需读取。本文件比 `SKILL.md` 的不可让步 Gate 更细。

## 视觉质量

- 不用 emoji 做功能图标，使用统一 SVG 图标库。
- 图标来自同一族、同一风格、同一笔画体系。
- 品牌资产比例和安全间距正确。
- 按压、hover、focus、disabled 状态不导致布局偏移。
- 颜色、阴影、圆角、间距使用设计 token。

## 交互

- 可点击元素有明确反馈。
- 触控目标 ≥ 44×44px。
- 微交互时长 150-300ms。
- 异步操作显示 loading / progress，并避免重复提交。
- 屏幕阅读器焦点顺序匹配视觉顺序。
- 关键操作不只依赖手势或 hover。

## 明暗模式

- 正文对比度 ≥ 4.5:1。
- 次要文字和非文本 UI 对比度 ≥ 3:1。
- 边框、分隔线、状态色在两种主题下都可见。
- Modal / Drawer 遮罩能明确隔离前景。
- 两种模式都实际测试。

## 布局

- 安全区域避让头部、底栏和 CTA。
- 滚动内容不被 sticky / fixed 元素遮挡。
- 375px / 768px / 1024px / 1440px 都正常。
- 无意水平滚动。
- 间距符合 4pt/8dp 节奏。
- 横屏模式下布局仍可读可操作。

## 可访问性

- 有意义图片有 alt 文本。
- 表单有 label、错误信息和恢复路径。
- 颜色不是唯一指示器。
- 支持 reduced-motion。
- aria role / state / label 正确。
- 动态字体或系统缩放下布局不崩溃。
